1. Quick Start with mode = g2rt

G2RT is PyAudioGaming's built-in unified cross-platform builder. Using the bundled pyaudiogaming/include/g2rt_toolkit.g2rt runtime package, you can build standalone distributables for Windows, Android, iOS, Linux, and macOS directly from Windows in seconds — without installing Gradle, Android SDK/NDK, or Xcode. 

project = main
project_full_name = MyAudioGame
rename_file = game
data = [res, maps]
mode = g2rt
platforms = [windows, android, linux, macos, ios]
arch = null
error_mode = 1
use_g2rt_tk = true
args_compile = [--package-id=com.mygame.app]

2. Build Commands

python -m pyaudiogaming.compile create build.txt
python -m pyaudiogaming.compile make
python -m pyaudiogaming.compile build.txt

3. Supported Platforms & CPU Architectures (mode = g2rt)

Platform Default arch Supported arch Values Output Format
windows x64 x64, x86 Standalone .exe + runtime
android arm64 arm64 (arm64-v8a), x86_64 Signed standalone .apk (ready to install)
linux x64 x64, arm64 (aarch64), armhf .tar.gz bundle with executable run.sh
macos arm64 arm64 (Apple Silicon), x64 (Intel) .zip containing .app bundle
ios arm64 arm64 (device), simulator Unsigned .ipa (install via Sideloadly/AltStore or sign with Apple cert)

4. Key Configuration Options

  • use_g2rt_tk = true (default): Uses the fast offline G2RT toolkit for Android, iOS, Linux, and macOS. Set use_g2rt_tk = false (or 0) to fall back to the legacy Briefcase / Gradle / BeeWare pipeline.
  • arch = [x64, arm64]: Build multiple CPU architectures in a single command, or leave arch = null for automatic platform defaults.
  • error_mode: 0 = write traceback to log file, 1 = display native error dialog (default), 2 = silent exit.
  • args_compile:
    • --package-id=com.yourname.game — Custom Android Application ID / Apple Bundle Identifier.
    • --keystore=path/to/key.pem — Custom PEM signing key + certificate for Android APK signing.
    • --no-default-reqs — Skip automatic bundling of default third-party dependencies.
    • Any non-flag package name (e.g. requests) is automatically resolved for the target OS and architecture and cached for fast offline rebuilds.

5. Performance & Caching

PyAudioGaming automatically caches extracted runtimes, resolved dependencies, and unchanged asset archives in %LOCALAPPDATA%\PyAudioGaming\ (or ~/.cache/pyaudiogaming/). First-time builds initialize the cache once; subsequent rebuilds complete in a few seconds.
