1. Overview

PyAudioGaming is a complete Python framework for building audio games and accessible cross-platform applications targeting Windows, Linux, macOS, Android, iOS, and Web.

Documentation Structure:
  • Step-by-Step Tutorials (01 → 06): Learn everything from your first window to 3D HRTF audio, forms, multi-backend GUI, storage, background workers, and shipping builds.
  • Dedicated Per-Module Guides & Parameter Tables: Every module has its own dedicated HTML page, TXT file, CSV spreadsheet, and JSON schema — never crammed into a single unreadable table.
  • Runnable Code Examples: Complete working Python scripts in docs/examples/.
