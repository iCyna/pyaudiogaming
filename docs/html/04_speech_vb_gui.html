1. Virtual Box Input & Neutral Keyboard Mode Switcher

Press Ctrl + Shift + Alt + Backspace inside vb.input() to cycle neutral virtual keyboard modes (standard, numeric, symbols, emoji, or your own custom_keyboards).

from pyaudiogaming import vb

msg = vb.input("Message", placeholder="Press Ctrl+Shift+Alt+Backspace for symbols...", window=wnd)
vb.info_box("Sent", f"You typed: {msg}")

2. 4-Backend Cross-Platform GUI (wx / Qt / Tk / Audio)

from pyaudiogaming import gui

w = gui.Window("Settings", (520, 420), backend="auto")
with w.page("General"):
    with w.group("Profile"):
        w.input("Username", value="player1")
        w.spin("Level", 1, 99, 10)
    with w.row():
        w.button("Save", lambda _: w.alert("Saved", str(w.values())))
        w.button("Close", lambda _: w.close())
w.run()
