Usage Guide & Examples

How to Use

  • Use say(text, i=True) to interrupt current speech, or i=False to queue after the current utterance.
  • Pass a list with split=True to speak multiple items sequentially without cutting each other off.
  • Use saync(text) for transient UI hints that should not pollute speech_history.
  • Use say3d(text, lx, ly, lz, sx, sy, sz) to speak from a 3D world coordinate.
from pyaudiogaming.speech import Speech

sp = Speech()
sp.say("Welcome!", i=True)
sp.say(["Health: 100", "Mana: 50"], split=True)
sp.say3d("Enemy spotted!", 0, 0, 0, 10, 4, 0)
sp.set_speech_rate(55)
