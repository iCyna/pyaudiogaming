Summary: Zero-bloat accessibility & TTS router with shared AudioPipeline (BASS PCM, LRU cache, 3D/HRTF/FX) and dedicated OS drivers: windows.py, android.py, ios.py, macos.py, linux.py.

Usage Guide & Examples

How to Use

  • Use Router() (alias Auto()) directly or through pyaudiogaming.speech.Speech().
  • Automatically lazy-loads only the current OS drivers (NVDA, ZDSR, JAWS, SystemAccess, Dolphin, PCTalker, SAPI5 on Windows; TalkBack/Jieshuo + AndroidTTS on Android; VoiceOver + AVSpeech / say on iOS/macOS; SpeechDispatcher + eSpeak on Linux).
  • All PCM-capable TTS engines share AudioPipeline for instant LRU-cached playback with full BASS volume, pan, mono, hrtf, fx, and speak3d(...).
from pyaudiogaming.g2access import Router

r = Router()
print("Available:", r.get_outputs(), "Active:", r.get_active_output())
r.output("Hello from G2Access!", interrupt=True)
r.speak3d("Behind you!", 0, 0, 0, 0, -5, 0)
