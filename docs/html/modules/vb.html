Summary: NVDA & TalkBack accessible UI engine featuring advanced text input (with Ctrl+Shift+Alt+Backspace neutral keyboard mode switcher), 23-control forms (group, tab, link, switch, table, tree, slider), and ready-to-use modal boxes.

Usage Guide & Examples

How to Use

  • Text Input: vb.input(title, text, password=False) — supports Undo/Redo (Ctrl+Z/Y), copy/paste, autocomplete suggestions, Ctrl+Shift+P (toggle password visibility), Ctrl+Shift+F (announce style), and Ctrl+Shift+Alt+Backspace to cycle neutral virtual keyboard modes (standard, numeric, symbols, emoji, custom_keyboards).
  • Forms: Build structured forms with vb.form(), begin_group()/end_group(), add(..., required=True, validator=fn), validate(), and open().
  • Modal Boxes: info_box(), warning_box(), success_box(), error_box(details=...) (with Copy Details button), choice_box(), progress_box(), confirm().
from pyaudiogaming import vb

f = vb.form(window=wnd, config={"label": "User Registration"})
f.begin_group("Account")
f.add("user", "input", value="", required=True, label="Username")
f.add("notify", "switch", value=True, label="Notifications")
f.add("docs", "link", url="https://example.com", label="Terms of Service")
f.end_group()
f.add("ok", "button", label="Register")
if f.open() == "ok":
    ok, errs = f.validate()
    if ok:
        vb.success_box("Done", f"Welcome, {f.get('user')}!")
