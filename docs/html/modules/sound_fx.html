Summary: High-level DSP effect presets and real-time BASS_FX / DX8 effect chains attached to any sound or mixer channel.

Usage Guide & Examples

How to Use

Attach audio effects such as reverb, parametric EQ, echo, chorus, compressor, or distortion to any playing channel for caves, underwater zones, radio filters, or muffled rooms.

from pyaudiogaming import sound_fx
# Attach FX to a channel handle from sound_pool.sound
