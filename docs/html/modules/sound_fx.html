Usage Guide & Examples

How to Use

  • Attach any preset by name via s.setfx("preset_name", **overrides), update live with s.set_fx_param(...), or remove with s.remove_fx(...) / s.remove_all_fx().
  • Steam Audio (45 built-in presets): 16 rooms (steam_small_room, steam_cave, steam_tunnel, steam_underwater, ...), 17 materials/direct (steam_wall_brick, steam_wall_concrete, steam_occlusion_heavy, steam_air_absorption, ...), 3 multi-path (steam_pathing_corridor, ...), and 9 surround/ambisonics (steam_virtual_surround_7_1, steam_ambisonics_2nd, ...).
  • Dynamic Colon-String FX: Pass inline parameter strings such as "reverb:0:-8:1800:0.4", "lowpass:650:0.707", "echo4:0.9:0.45:0.4:0.3:1", "rotate:0.5", "steam_reverb:1.4:1.1:0.7", "steam_direct:0.8:2.5", or "steam_ambisonics:2".
from pyaudiogaming.sound_pool import output, sound
output(ThreeD=True)
s = sound()
s.stream("res/sounds/voice.ogg", ThreeD=True)
s.setfx("steam_wall_brick", occlusion=0.75)
s.setfx("lowpass:800:0.707")
s.play()
