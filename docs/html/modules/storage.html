Summary: Guaranteed-writable persistent storage solving mobile APK asset overwrites: uses filesDir ($HOME) on Android/iOS, AppData/XDG/portable on Desktop, with atomic writes (.tmp + fsync + os.replace) and automatic .bak recovery.

Usage Guide & Examples

How to Use

  • Use ConfigStore for settings (dict-like access, schema defaults, JSON/Pickle/AES encryption, and version migration).
  • Use Storage directly for arbitrary save files, account files, logs, or encrypted payloads.
from pyaudiogaming.storage import ConfigStore, Storage

cfg = ConfigStore("my_game", filename="data/options.json", defaults={"vol": 90.0}, portable=True)
cfg.load()
cfg["vol"] = 75.0
cfg.save()

st = Storage("my_game", portable=True)
st.save_encrypted("data/account.dat", {"user": "alice"}, password="secret")
