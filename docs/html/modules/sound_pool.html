Summary: Full-featured BASS audio engine: output/input device management, streaming & cached samples, fading, binaural HRTF, Steam Audio wall occlusion, push streams, and microphone recording.

Usage Guide & Examples

How to Use

  1. Initialize audio output once with out = output(device=-1).
  2. Create a sound() object, call stream(path), configure volume/pan/pitch, and call play() or play_looped().
  3. For 3D binaural audio, pass mono=True, call attach_hrtf_dsp(), and call update_hrtf_listener(...) each frame.
  4. For real-time voice chat or procedural audio, use record(mono=True, draw=True) and sound.stream("", mono=True, draw=True) + push(pcm_bytes).
from pyaudiogaming.sound_pool import output, sound, update_hrtf_listener

out = output(device=-1, frequency=44100)
s = sound()
s.stream("res/sounds/beacon.ogg", mono=True)
s.attach_hrtf_dsp()
s.volume = 80
s.play_looped()

update_hrtf_listener(0, 0, 1.7, 0, 1, 0, 0, 0, 1)
