Summary: Accessible game menu supporting keyboard arrows, '&K' shortcut hotkeys, wrap-around navigation, custom cursor/enter/cancel sounds, and mobile TalkBack touch gestures.

Usage Guide & Examples

How to Use

  1. Create m = menu() and call m.init(wnd, ttl='Title', items=['Start&S', 'Options&O', 'Exit&E']).
  2. Call m.open() once before entering your loop.
  3. Inside your loop, call res = m.frameUpdate(): it returns None while browsing, -1 on Escape/Cancel, or the 0-based item index when activated.
from pyaudiogaming.menu import menu

m = menu()
m.init(wnd, ttl="Main Menu", items=["Play&P", "Settings&S", "Quit&Q"], keyRead=True, readNP=True)
m.open()

while True:
    wnd.frameUpdate()
    res = m.frameUpdate()
    if res == 0: start_game()
    elif res == 1: open_settings()
    elif res in (2, -1): break
