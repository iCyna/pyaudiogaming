Summary: Zero-thread, nanosecond-precision monotonic timing suite: Timer (pause/scale/countdown/drift-free), CooldownManager, TimerScheduler (min-heap), FrameClock (FPS/dt/fixed_steps), Stopwatch, and RateLimiter.

Usage Guide & Examples

How to Use

  • Basic Timer: t = Timer(), check t.elapsed (int ms), call t.restart(). Works before pygame.init() and on headless servers.
  • Cooldowns: Use CooldownManager() and if cd.use("skill", 2000): ....
  • Scheduled Callbacks: Use TimerScheduler() with after(ms, fn) / every(ms, fn) and call sched.update() each frame (100% single-threaded).
from pyaudiogaming.timer import Timer, CooldownManager, TimerScheduler, FrameClock

cd = CooldownManager()
sched = TimerScheduler()
clock = FrameClock(target_fps=60)

if cd.use("fireball", 3000):
    sched.after(3000, lambda: print("Fireball ready!"))
# Each frame:
dt = clock.tick()
sched.update()
