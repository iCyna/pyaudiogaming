Usage Guide & Examples

How to Use

  1. Trigger instant feedback with haptics.preset("click"), haptics.preset("hit_heavy"), or haptics.vibrate(duration_ms=60, strength=0.8).
  2. Play multi-step rhythms with haptics.pattern([(40, 0.8), (60, 0.0), (100, 1.0)]).
  3. Call haptics.update() once per frame in your game loop.
from pyaudiogaming import haptics

haptics.set_intensity(0.85)
haptics.preset("explosion")
# Inside game loop:
haptics.update()
