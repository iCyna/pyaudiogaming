Summary: Low-level BASS initialization, on-demand codec plugin loader (FLAC, Opus, AAC, ALAC, WMA, MPC, MIDI), mmap/RAM preloading, HSAMPLE caching, and SPAK memory buffer registry.

Usage Guide & Examples

How to Use

Most apps use sound_pool.output(), which calls control.init_sound() automatically. Use control directly for custom memory buffers, explicit codec loading, or cache cleanup.

from pyaudiogaming.sound_modules import control

control.init_sound(dev=-1, freq=44100)
control.load_codec_plugins()
control.load_sound_file("res/sounds/click.ogg", key="ui_click", target="both")
