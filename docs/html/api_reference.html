Per-Module API & Parameter Reference Hub

Each module has its own dedicated page with complete usage guides, code examples, and cleanly split parameter tables. Separate CSV/JSON/TXT files per module are also available in docs/reference/modules/ and docs/txt/modules/.

pyaudiogaming.window

4 classes44 APIs

Core application window managing the SDL2/pygame loop, keyboard edge/hold detection, mobile touch gestures (tap/swipe), screen-reader speech forwarding, and SPAK loading.

pyaudiogaming.speech

1 classes44 APIs

Unified speech wrapper supporting NVDA, JAWS, SAPI5, VoiceOver, TalkBack, speech history, voice/rate/pitch/volume controls, and 3D positional TTS.

pyaudiogaming.g2access

17 classes265 APIs

Zero-bloat accessibility & TTS router with shared AudioPipeline (BASS PCM, LRU cache, 3D/HRTF/FX) and dedicated OS drivers: windows.py, android.py, ios.py, macos.py, linux.py.

pyaudiogaming.sound_pool

10 classes176 APIs

Complete BASS audio engine: playback, 3D binaural HRTF & Steam Audio occlusion, Tempo/Tone (0..100+%), Reverse, URL streaming, LUFS loudness, native WAV/MP3/OGG/FLAC/OPUS encoding, Tags, Sync callbacks, Mixer/Split/Matrix, MIDI, VST, WASAPI, and live recording.

pyaudiogaming.sound_fx

1 classes73 APIs

High-level DSP & Steam Audio acoustic FX catalog: 17 DX8 Reverbs, Freeverb, Echo/Echo2/Echo3/Echo4, Rotate, Chorus, Flanger, Phaser, AutoWah, Compressor, Distortion, PitchShift, 12 Biquad Filters, 45 Steam Audio presets, and dynamic colon-string parser.

pyaudiogaming.sound_modules.control

3 classes36 APIs

Low-level BASS initialization, on-demand codec plugin loader (FLAC, Opus, AAC, ALAC, WMA, MPC, MIDI), mmap/RAM preloading, HSAMPLE caching, and SPAK memory buffer registry.

pyaudiogaming.menu

1 classes30 APIs

Accessible game menu supporting keyboard arrows, '&K' shortcut hotkeys, wrap-around navigation, custom cursor/enter/cancel sounds, and mobile TalkBack touch gestures.

pyaudiogaming.vb

3 classes59 APIs

NVDA & TalkBack accessible UI engine featuring advanced text input (with Ctrl+Shift+Alt+Backspace neutral keyboard mode switcher), 23-control forms (group, tab, link, switch, table, tree, slider), and ready-to-use modal boxes.

pyaudiogaming.gui

5 classes146 APIs

Write GUI code once and run natively on wxPython (Windows), PySide6/PyQt6 (Linux/macOS), Tkinter (stdlib fallback), or AudioWindow/vb.form (Android/iOS/Web).

pyaudiogaming.inputBox

0 classes5 APIs

Cross-platform input prompts, message boxes, and file/folder pickers using native OS dialogs (Win32/Cocoa/GTK/Android) with automatic vb.form SDL fallback.

pyaudiogaming.key

0 classes4 APIs

Complete key-name to pygame keycode lookup table (<code>ksum</code>) and shortcut chord parser (<code>chord('ctrl+shift+s')</code>).

pyaudiogaming.timer

7 classes86 APIs

Zero-thread, nanosecond-precision monotonic timing suite: Timer (pause/scale/countdown/drift-free), CooldownManager, TimerScheduler (min-heap), FrameClock (FPS/dt/fixed_steps), Stopwatch, and RateLimiter.

pyaudiogaming.haptics

1 classes19 APIs

Unified vibration & rumble controller for Android (Vibrator/VibrationEffect), iOS (UIImpactFeedbackGenerator), Windows XInput gamepads, and SDL2/pygame joysticks with 13 built-in presets and non-blocking patterns.

pyaudiogaming.notify

0 classes6 APIs

Send native OS notifications (Windows Toast, Android NotificationManager, macOS, Linux) and wake locked/sleeping screens with Full-Screen Intent (Android) or Win32 display wake & foreground bring-to-front (Windows).

pyaudiogaming.app_link

1 classes9 APIs

Register file extensions (.mp3, .ogg, .wav) without Admin on Windows (HKCU) or Linux (.desktop), read launched files / Android content:// URIs, and forward newly opened files to an already-running app instance.

pyaudiogaming.storage

2 classes28 APIs

Guaranteed-writable persistent storage solving mobile APK asset overwrites: uses filesDir ($HOME) on Android/iOS, AppData/XDG/portable on Desktop, with atomic writes (.tmp + fsync + os.replace) and automatic .bak recovery.

pyaudiogaming.worker

3 classes27 APIs

Run heavy CPU/IO tasks without freezing your game loop. Automatically selects process on Desktop (with freeze_support and auto-thread fallback for lambdas), thread on Android/iOS, and inline on Web.

pyaudiogaming.input_map

1 classes20 APIs

Map named actions to keyboard keys/chords, mobile touch taps/swipes, mouse buttons, and gamepad buttons/sticks, with interactive rebinding, TTS descriptions, and JSON persistence.

pyaudiogaming.file

1 classes16 APIs

File helper supporting JSON, Pickle, and plain-text serialization with optional two-layer Fernet + AES-CBC encryption.

pyaudiogaming.utils

1 classes47 APIs

Zero-dependency game utilities: clamp/lerp/remap/clock_direction/db_to_linear, weighted random, fuzzy search, cross-platform clipboard (copy_text/paste_text), open_url, SHA-256 hashing, and SPAK binary audio archiving.

pyaudiogaming.buffer

0 classes0 APIs

Central in-memory registry holding the active window frame, audio device handles, stream/sample buffers, and active sound pool references.

pyaudiogaming.common

0 classes2 APIs

Lightweight filesystem, process execution, and environment utilities shared across PyAudioGaming modules.

pyaudiogaming.system

0 classes13 APIs

Detects OS (Windows/Linux/macOS/Android/iOS), CPU architecture (x64/x86/arm64-v8a/aarch64/armhf), frozen bundle paths, and loads platform-specific native libraries (.dll/.so/.dylib).

pyaudiogaming.compile

0 classes20 APIs

Single-config build tool driving PyInstaller, Nuitka, Cython/GCC/MSVC, cx_Freeze, and BeeWare (Briefcase) for Desktop, Android APK, iOS Xcode/IPA, and Web.
