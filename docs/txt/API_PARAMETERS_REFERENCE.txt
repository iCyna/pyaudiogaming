PYAUDIOGAMING — COMPLETE API & PARAMETER REFERENCE
========================================================================


[WINDOW]
----------------------------------------
* Window.init(x, y, ttl, vv=0, show_vv=False, author='')
  Types  : int, int, str, int, bool, str  ->  Returns: None
  Desc   : Initialize the game window, title, and keyboard/mouse/touch input handlers.
  Example: wnd = Window(); wnd.init(800, 600, 'My Audio Game')
* Window.frameUpdate()
  Types  : None  ->  Returns: None
  Desc   : Process one frame of input events (keyboard, mouse, touch) and keep the loop responsive.
  Example: while True: wnd.frameUpdate()
* Window.keyPressed(key)
  Types  : str | int  ->  Returns: bool
  Desc   : Return True on the exact frame a key is newly pressed.
  Example: if wnd.keyPressed('space'): player.jump()
* Window.keyPressing(key, t=0)
  Types  : str | int, int (ms)  ->  Returns: bool
  Desc   : Return True while a key is held down, optionally throttling repeats every t milliseconds.
  Example: if wnd.keyPressing('right', 150): player.step_right()
* Window.tap(fingers=1, count=1, zone=None)
  Types  : int, int, str | None  ->  Returns: bool | int
  Desc   : Detect single or multi-finger taps on mobile touchscreens, optionally filtered by screen zone.
  Example: if wnd.tap(fingers=1, count=2, zone='left-play'): player.jump()
* Window.swipe / keySlide(direction, fingers=1, zone=None)
  Types  : str, int, str | None  ->  Returns: bool
  Desc   : Detect directional touch swipes ('left', 'right', 'up', 'down') on mobile devices.
  Example: if wnd.swipe('right', fingers=1): menu_next()
* Window.say(text, i=True, split=False)
  Types  : str | list, bool, bool  ->  Returns: None
  Desc   : Speak text via active Screen Reader or TTS (i=True interrupts current speech).
  Example: wnd.say('Welcome to the game!', i=True)
* Window.wait(ms)
  Types  : int  ->  Returns: None
  Desc   : Pause safely for ms milliseconds.
  Example: wnd.wait(100)

[SPEECH]
----------------------------------------
* Speech.say(text, i=True, split=False)
  Types  : str | list, bool, bool  ->  Returns: None
  Desc   : Output speech via NVDA, JAWS, SAPI5, VoiceOver, or TalkBack and append to speech_history.
  Example: wnd.speech.say(['HP: 100', 'MP: 50'], split=True)
* Speech.saync(string, i=True)
  Types  : str, bool  ->  Returns: None
  Desc   : Speak text without adding it to speech_history.
  Example: wnd.speech.saync('Typing...', i=True)
* Speech.say3d(text, lx, ly, lz, sx, sy, sz, i=True)
  Types  : str, float x6, bool  ->  Returns: None
  Desc   : Speak TTS positioned in 3D space between listener (l) and source (s).
  Example: wnd.speech.say3d('Over here!', 0, 0, 0, 8, 2, 0)
* Speech.set_speech_rate / pitch / volume(value)
  Types  : int  ->  Returns: bool
  Desc   : Adjust TTS speaking rate, pitch, or volume.
  Example: wnd.speech.set_speech_rate(60)

[SOUND_POOL]
----------------------------------------
* output / OutputManager(device=-1, frequency=44100, period=10, bbuffer=500)
  Types  : int, int, int, int  ->  Returns: OutputManager
  Desc   : Initialize the BASS audio output device (-1 selects the default OS device).
  Example: audio = output(device=-1, frequency=44100)
* sound.stream(filename, mono=False, decode=False, draw=False)
  Types  : str, bool, bool, bool  ->  Returns: bool
  Desc   : Load an audio stream from disk, SPAK archive, or create a live push stream (draw=True).
  Example: bgm = sound(); bgm.stream('res/sounds/theme.ogg')
* sound.play / play_looped / pause / stop()
  Types  : None  ->  Returns: bool
  Desc   : Start, loop continuously, pause, or stop playback.
  Example: bgm.volume = 60; bgm.play_looped()
* sound.fadeout / fadein(duration_ms, value=...)
  Types  : int, float  ->  Returns: None
  Desc   : Smoothly fade volume down or up over duration_ms milliseconds.
  Example: bgm.fadeout(900)
* sound.attach_hrtf_dsp(priority=0)
  Types  : int  ->  Returns: bool
  Desc   : Attach real-time binaural 3D HRTF (Steam Audio / Phonon) DSP to this channel.
  Example: s = sound(); s.stream('step.ogg', mono=True); s.attach_hrtf_dsp()
* record(filename='', mono=True, freq=44100, draw=False)
  Types  : str, bool, int, bool  ->  Returns: record
  Desc   : Record live microphone audio to disk or push PCM buffers for real-time voice chat.
  Example: rec = record(mono=True, freq=44100)

[TIMER]
----------------------------------------
* Timer(duration=0, paused=False, scale=1.0, auto_start=True)
  Types  : float, bool, float, bool  ->  Returns: Timer
  Desc   : Monotonic nanosecond-precision timer (no pygame.init required) with pause, time-scale, countdown, and serialization.
  Example: t = Timer(duration=3000); print(t.elapsed, t.remaining, t.progress)
* Timer.ready / consume / consume_all(ms, auto_restart=False)
  Types  : float, bool  ->  Returns: bool | int
  Desc   : One-line cooldown check or drift-free fixed-interval tick consumption.
  Example: if t.ready(500, auto_restart=True): shoot()
* CooldownManager(scale=1.0)
  Types  : float  ->  Returns: CooldownManager
  Desc   : Manage named cooldowns in one place: use(), is_ready(), remaining(), reduce(), pause_all().
  Example: cd = CooldownManager(); if cd.use('dash', 2000): player.dash()
* TimerScheduler(scale=1.0, on_error=None)
  Types  : float, callable  ->  Returns: TimerScheduler
  Desc   : Single-threaded min-heap callback scheduler: after(), every(), cancel(), cancel_by_tag(), update().
  Example: sched = TimerScheduler(); sched.after(1500, on_expire); sched.update()
* FrameClock(target_fps=0.0, max_dt_ms=100.0)
  Types  : float, float  ->  Returns: FrameClock
  Desc   : Game-loop delta time (dt), smoothed FPS, frame limiter, and fixed_steps() physics accumulator.
  Example: clk = FrameClock(target_fps=60); dt = clk.tick()
* Stopwatch / RateLimiter(max_calls, per_ms)
  Types  : int, float  ->  Returns: Object
  Desc   : Split lap profiling (Stopwatch) and token-bucket anti-spam throttling (RateLimiter).
  Example: rl = RateLimiter(max_calls=5, per_ms=1000); if rl.allow(): send_chat()
