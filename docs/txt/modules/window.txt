========================================================================
MODULE: pyaudiogaming.window
window — Game Window, Event Loop & Touch/Key Input
========================================================================

SUMMARY:
Core application window managing the SDL2/pygame loop, keyboard edge/hold detection, mobile touch gestures (tap/swipe), screen-reader speech forwarding, and SPAK loading.
