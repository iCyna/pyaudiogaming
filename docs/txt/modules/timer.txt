========================================================================
MODULE: pyaudiogaming.timer
timer — Single-Threaded High-Precision Timers, Cooldowns & Scheduler
========================================================================

SUMMARY:
Zero-thread, nanosecond-precision monotonic timing suite: Timer (pause/scale/countdown/drift-free), CooldownManager, TimerScheduler (min-heap), FrameClock (FPS/dt/fixed_steps), Stopwatch, and RateLimiter.

[MODULE FUNCTIONS]
----------------------------------------
* get_ticks() -> int
  Return monotonic milliseconds since module import (high-resolution, never jumps backwards).
* get_ticks_us() -> int
  Return monotonic microseconds since module import.
* get_ticks_sec() -> float
  Return monotonic seconds (float) since module import.
* format_duration(ms: float, style: str='clock') -> str
  Format milliseconds into a human-readable string.

[CLASS Timer]
----------------------------------------
High-precision game timer supporting pause/resume, time scaling, countdowns, fixed-interval ticks, forcing/advancing, serialization, and context-manager profiling.
* Timer.__init__(duration: float=0, paused: bool=False, scale: float=1.0, auto_start: bool=True) -> any [constructor]
* Timer.elapsed() -> int [property]
  Elapsed time in integer milliseconds (backwards-compatible).
* Timer.elapsed_float() -> float [property]
  Elapsed time in floating-point milliseconds.
* Timer.elapsed_us() -> int [property]
  Elapsed time in integer microseconds.
* Timer.elapsed_seconds() -> float [property]
  Elapsed time in seconds (float).
* Timer.paused() -> bool [property]
* Timer.running() -> bool [property]
* Timer.scale() -> float [property]
  Time dilation factor (1.0 = normal, 0.5 = slow-mo, 2.0 = 2x speed).
* Timer.duration() -> float [property]
  Configured countdown duration in milliseconds (0 if none).
* Timer.remaining() -> int [property]
  Remaining milliseconds until ``duration`` expires (clamped to >= 0).
* Timer.remaining_float() -> float [property]
* Timer.remaining_seconds() -> float [property]
* Timer.progress() -> float [property]
  Completion ratio from 0.0 to 1.0 when ``duration > 0``.
* Timer.expired() -> bool [property]
  True when ``duration > 0`` and elapsed >= duration.
* Timer.restart(duration: float=None, paused: bool=False) -> any [method]
  Reset elapsed time to 0 and start (unless ``paused=True``).
* Timer.start(duration: float=None) -> any [method]
  Start or resume the timer. Optionally set a new duration and reset.
* Timer.pause() -> any [method]
  Freeze the timer at its current elapsed value.
* Timer.resume() -> any [method]
  Resume a paused timer from where it left off.
* Timer.toggle_pause() -> bool [method]
  Toggle paused state and return the new ``paused`` boolean.
* Timer.stop() -> any [method]
  Stop and reset elapsed time to 0.
* Timer.force(ms: float) -> any [method]
  Force the timer's elapsed time to a specific millisecond value (like BGT ``timer.force``).
* Timer.advance(delta_ms: float) -> any [method]
  Add ``delta_ms`` milliseconds to the current elapsed time.
* Timer.rewind(delta_ms: float, clamp_zero: bool=True) -> any [method]
  Subtract ``delta_ms`` milliseconds from the current elapsed time.
* Timer.ready(cooldown_ms: float=None, auto_restart: bool=False) -> bool [method]
  Check whether ``cooldown_ms`` (or ``self.duration``) has elapsed.
* Timer.consume(interval_ms: float=None) -> bool [method]
  Drift-free periodic trigger: if ``elapsed >= interval``, subtracts one interval (preserving sub-millisecond remainder) and returns ``True``.
* Timer.consume_all(interval_ms: float=None, max_ticks: int=None) -> int [method]
  Consume all completed intervals and return how many occurred (drift-free).
* Timer.format(style: str='clock', remaining: bool=False) -> str [method]
  Format either elapsed or remaining time using ``format_duration``.
* Timer.to_dict() -> dict [method]
* Timer.from_dict(data) -> 'Timer' [method]

[CLASS FrameClock]
