========================================================================
MODULE: pyaudiogaming.gui
gui — Unified 4-Backend Cross-Platform GUI (wx / Qt / Tk / Audio)
========================================================================

SUMMARY:
Write GUI code once and run natively on wxPython (Windows), PySide6/PyQt6 (Linux/macOS), Tkinter (stdlib fallback), or AudioWindow/vb.form (Android/iOS/Web).

[MODULE FUNCTIONS]
----------------------------------------
* detect_gui_backend(preferred: str='auto') -> str
  Return the best available GUI backend name: ``'wx'``, ``'qt'``, ``'tk'``, or ``'audio'``.
