========================================================================
MODULE: pyaudiogaming.storage
storage — Cross-Platform Persistent Storage & ConfigStore
========================================================================

SUMMARY:
Guaranteed-writable persistent storage solving mobile APK asset overwrites: uses filesDir ($HOME) on Android/iOS, AppData/XDG/portable on Desktop, with atomic writes (.tmp + fsync + os.replace) and automatic .bak recovery.

[MODULE FUNCTIONS]
----------------------------------------
* get_platform_data_dir(app_name: str, portable: bool=False, portable_dir: str='res') -> Path
  Return a guaranteed-writable persistent directory for ``app_name`` on any OS.
* atomic_write_bytes(path, data: bytes, backup: bool=True) -> any
  Write bytes atomically via ``.tmp`` + ``fsync`` + ``os.replace``.
* atomic_write_text(path, text: str, encoding: str='utf-8', backup: bool=True) -> any
