========================================================================
MODULE: pyaudiogaming.worker
worker — Cross-Platform Background TaskPool & SharedState
========================================================================

SUMMARY:
Run heavy CPU/IO tasks without freezing your game loop. Automatically selects process on Desktop (with freeze_support and auto-thread fallback for lambdas), thread on Android/iOS, and inline on Web.

[MODULE FUNCTIONS]
----------------------------------------
* enable_freeze_support() -> any
  Safely call ``multiprocessing.freeze_support()`` once (prevents fork-bomb in PyInstaller/Nuitka).
* detect_best_mode(preferred: str='auto') -> str
  Resolve requested execution mode (``'auto'``, ``'process'``, ``'thread'``, ``'inline'``) to a mode guaranteed to work on the current OS.
